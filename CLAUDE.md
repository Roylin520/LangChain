# Claude Code Project Guide

## Project goal

This repository is a teaching starter pack for an 18-hour Traditional Chinese workshop on LangChain agentic AI applications.

## Coding rules

- Use Python 3.10+.
- Keep examples beginner-friendly and heavily commented.
- Use Traditional Chinese (Taiwan) in user-facing explanations.
- Do not hard-code API keys or secrets.
- Prefer small, testable functions.
- When editing LangChain code, check whether the current API belongs to LangChain v1.

## Teaching style

Explain actual mechanisms: model call, tool execution, middleware hooks, state, memory, MCP transport, and structured output validation. Avoid vague analogies.
